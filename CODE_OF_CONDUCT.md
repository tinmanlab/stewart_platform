# A learning-friendly community

Welcome questions from first-time learners as well as specialists. Critique claims and code, not people. Explain unfamiliar terms, cite evidence, credit contributors and respect privacy. Harassment, threats, discriminatory abuse and deliberate disruption are not acceptable.

The maintainer may edit or remove harmful content and restrict participation. Raise concerns with the maintainer through an available private GitHub reporting channel; avoid publishing personal information. When no private channel is available, ask for one without including sensitive details. Apply this guidance consistently to project discussions, issues and reviews.
