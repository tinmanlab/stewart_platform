# Security and safe use

This is a local educational simulator, not a motor controller or safety system. Do not connect its outputs directly to physical equipment. Projects are untrusted input: retain schema/range checks and the import size limit. Do not use `eval` on imported data or add executable project fields.

For a security issue, use GitHub's **Security → Report a vulnerability** when private reporting is enabled. Otherwise open a minimal issue asking the maintainer for a private reporting channel, without exploit payloads, secrets or personal data. Do not assume an unconfigured email address or reporting service exists.

Only the maintained English source is a candidate for fixes. The Korean v1.0 file is a historical archive, not a separately maintained security branch. Review repository status and advisories before redistributing it. Never commit credentials or expand CI token permissions to work around a deployment error.
